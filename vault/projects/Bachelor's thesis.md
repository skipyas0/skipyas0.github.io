My thesis is [accessible here](https://dspace.cvut.cz/handle/10467/123489). It focused on Prompt Optimization in Large Language Models. I gained experience with agentic AI, API usage, cluster compute, and general optimization techniques such as genetic algorithms.

The relevant code is available [here](https://github.com/skipyas0/prompt_optimizer), and includes the prompt optimizer as well as a simple inference framework inspired by DSPy, featuring some inference-time scaling techniques.
