# Writing for the website

- `cv.md` is shown on the **About** page.
- Every note in `projects/` becomes a tile on the **Projects** page. Its URL is the file name, e.g. `projects/My Thing.md` → `#projects/my-thing`.
- New note → run the **Templates: Insert template** command → `Project`.
- `type` decides the tile style: `project`, `experiment` or `publication` (anything else gets the default style).
- Notes with `draft: true` are not published.
- Pasted images go to `assets/` and work on the site as-is.
