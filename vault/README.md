# Writing for the website

- `cv.md` is shown on the **About** page.
- Every note in `projects/` becomes a tile on the **Projects** page and its own page, named after the file: `projects/My Thing.md` → `vojtechklouda.com/p/my-thing/`.
- New note → run the **Templates: Insert template** command → `Project`.
- `type` decides the tile style: `project`, `experiment` or `publication` (anything else gets the default style).
- Notes with `draft: true` are not published.
- Pasted images go to `assets/` and work on the site as-is.
- `image` (optional) is the preview picture for LinkedIn etc.: a file name from `assets/`, e.g. `cover.png`.
- When sharing a link, add `?ref=` to see where visits come from, e.g. `vojtechklouda.com/p/my-thing/?ref=linkedin`.
